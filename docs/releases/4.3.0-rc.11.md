# SaltsUtils 4.3.0-rc.11

This release rebuilds the SaltsUtils 4.3.0 RC SDK against the published
Salts.Native 2.3.0-rc.16 ABI used by the current CNet TLS runtime.

- Pins the immutable six-RID Salts.Native 2.3.0-rc.16 release and verifies its
  source commit and package digest before every native build.
- Preserves the SaltsUtils public API and the rc.10 source baseline.
- Publishes six matching SDK manifests so CHttp and Flowie can be rebuilt
  without mixing Salts rc.15 and rc.16 DLLs in one process.

The release CI builds all six SDK targets and runs the complete native host
CTest suites before packaging. Downstream CHttp and Flowie validation remains
separate and must use this exact package together with Salts.Native rc.16.
